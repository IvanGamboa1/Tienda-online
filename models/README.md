# K1KO shirt model

`k1ko-shirt.glb` is based on the optimized web model from [ISAIASNIAUPARI/REPO_BLENDER](https://github.com/ISAIASNIAUPARI/REPO_BLENDER/tree/main/camiseta).

The repository author is the user's friend and permission to use and edit the model was confirmed by the user. Its embedded textures have been removed, and `designer.js` softens the front logo and shoulder details while preserving the original 3D geometry. The shirt is rendered with a matte diffuse material. The GLB remains Draco-compressed and is loaded with Three.js `GLTFLoader` and `DRACOLoader`.
